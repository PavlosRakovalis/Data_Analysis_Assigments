# Άσκηση 7 - Λύση

Δίνεται αύξων αριθμός:

```text
x = 211
```

Τα δεδομένα του συστήματος EOQ είναι:

```text
Εβδομαδιαία ζήτηση d = 80 μονάδες/εβδομάδα
Ετήσια ζήτηση D = 80 · 52 = 4.160 μονάδες/έτος
Χρόνος ικανοποίησης παραγγελίας L = 1 εβδομάδα
Κόστος παραγγελίας S = 50 + x = 50 + 211 = 261 €/παραγγελία
Βέλτιστη ποσότητα παραγγελίας Q = 100 + x = 100 + 211 = 311 μονάδες
```

## α) Στάθμη παραγγελίας

Η στάθμη παραγγελίας, χωρίς απόθεμα ασφαλείας, είναι:

```text
ROP = d · L
    = 80 · 1
    = 80 μονάδες
```

Άρα νέα παραγγελία πρέπει να δίνεται όταν το απόθεμα πέσει στις:

```text
80 μονάδες
```

## β) Μέσο απόθεμα, χρόνος μεταξύ παραγγελιών, κυκλοφοριακή ταχύτητα και διάρκεια αποθεμάτων

Το μέσο απόθεμα στο μοντέλο EOQ είναι:

```text
Iμέσο = Q / 2
      = 311 / 2
      = 155,5 μονάδες
```

Ο χρόνος μεταξύ δύο διαδοχικών παραγγελιών είναι:

```text
T = Q / d
  = 311 / 80
  = 3,8875 εβδομάδες
```

Άρα:

```text
T = 3,89 εβδομάδες
```

Ο αριθμός παραγγελιών ανά έτος είναι:

```text
N = D / Q
  = 4.160 / 311
  = 13,38 παραγγελίες/έτος
```

Η κυκλοφοριακή ταχύτητα αποθεμάτων είναι:

```text
Κυκλοφοριακή ταχύτητα = Ετήσια ζήτηση / Μέσο απόθεμα
                      = 4.160 / 155,5
                      = 26,75 φορές/έτος
```

Η διάρκεια των αποθεμάτων σε εβδομάδες είναι:

```text
Διάρκεια αποθεμάτων = Μέσο απόθεμα / Εβδομαδιαία ζήτηση
                    = 155,5 / 80
                    = 1,94375 εβδομάδες
```

Άρα:

```text
Διάρκεια αποθεμάτων = 1,94 εβδομάδες
```

## γ) Μέσο ετήσιο συνολικό κόστος παραγγελιών και διατήρησης αποθεμάτων

Το ετήσιο κόστος παραγγελιών είναι:

```text
Κόστος παραγγελιών = (D / Q) · S
                  = (4.160 / 311) · 261
                  = 3.491,19 €
```

Επειδή η ποσότητα `Q = 311` είναι η βέλτιστη EOQ, στο άριστο σημείο ισχύει:

```text
Ετήσιο κόστος παραγγελιών = Ετήσιο κόστος διατήρησης αποθεμάτων
```

Άρα:

```text
Ετήσιο κόστος διατήρησης = 3.491,19 €
```

Το μέσο ετήσιο συνολικό κόστος παραγγελιών και διατήρησης είναι:

```text
TC = 3.491,19 + 3.491,19
   = 6.982,38 €
```

## δ) Κόστος διατήρησης μίας μονάδας αποθέματος για ένα έτος

Ο τύπος της οικονομικής ποσότητας παραγγελίας είναι:

```text
Q = sqrt(2DS / H)
```

Άρα:

```text
H = 2DS / Q^2
```

Υπολογιστικά:

```text
H = 2 · 4.160 · 261 / 311^2
  = 2.171.520 / 96.721
  = 22,45 €/μονάδα/έτος
```

Επομένως, το κόστος διατήρησης μίας μονάδας αποθέματος για ένα έτος είναι:

```text
22,45 €/μονάδα/έτος
```
