# Άσκηση 2 - Λύση

Δίνεται αύξων αριθμός:

```text
x = 211
```

Κάθε ξύλινη πολυθρόνα απαιτεί:

```text
18 kg ξυλείας
```

Η εβδομαδιαία ποσότητα ξυλείας που προμηθεύεται η εταιρία είναι:

```text
450 + 6x = 450 + 6 · 211 = 1.716 kg/εβδομάδα
```

Άρα ο ρυθμός παραγωγής, με βάση τη διαθέσιμη ξυλεία, είναι:

```text
Ρυθμός παραγωγής = 1.716 / 18 = 95,33 πολυθρόνες/εβδομάδα
```

Στο εργοστάσιο υπάρχουν κατά μέσο όρο:

```text
WIP = 120 πολυθρόνες
```

Με βάση τον νόμο του Little:

```text
Μέσο απόθεμα σε παραγωγή = Ρυθμός παραγωγής · Μέσος χρόνος ροής
```

Άρα:

```text
Μέσος χρόνος ροής = Μέσο απόθεμα σε παραγωγή / Ρυθμός παραγωγής
                  = 120 / 95,33
                  = 1,2587 εβδομάδες
```

Επομένως, ο μέσος χρόνος που απαιτείται για την ολοκλήρωση της παραγωγής μίας πολυθρόνας είναι:

```text
1,26 εβδομάδες
```

Σε ημέρες:

```text
1,2587 · 7 = 8,81 ημέρες
```

Άρα η παραγωγή μίας ξύλινης πολυθρόνας ολοκληρώνεται, κατά μέσο όρο, σε περίπου:

```text
1,26 εβδομάδες ή 8,81 ημέρες
```

από τη στιγμή που η ξυλεία είναι διαθέσιμη στο εργοστάσιο.
