# Άσκηση 3 - Λύση

Δίνεται αύξων αριθμός:

```text
x = 211
```

## Δεδομένα μετά τη στρογγυλοποίηση

Δυναμικότητες εργοστασίων:

```text
Εργοστάσιο 1: 150 μονάδες/μήνα
Εργοστάσιο 2: 100 + x/3 = 100 + 211/3 = 170,33 ≈ 170 μονάδες/μήνα
```

Συνολική δυναμικότητα:

```text
150 + 170 = 320 μονάδες/μήνα
```

Ζήτηση αποθηκών:

```text
Α = 50
Β = 60
Γ = 70
Δ = 60 + x/5 = 60 + 211/5 = 102,20 ≈ 102
```

Συνολική ζήτηση:

```text
50 + 60 + 70 + 102 = 282 μονάδες/μήνα
```

Επειδή η συνολική δυναμικότητα είναι μεγαλύτερη από τη συνολική ζήτηση, προστίθεται μία εικονική αποθήκη Ε, η οποία αντιπροσωπεύει την αχρησιμοποίητη δυναμικότητα:

```text
Εικονική ζήτηση = 320 - 282 = 38 μονάδες
```

Το κόστος μεταφοράς προς την εικονική αποθήκη είναι μηδενικό.

## Αρχική λύση με τη μέθοδο της ΒΔ γωνίας

Η αρχική κατανομή είναι:

|  | Α | Β | Γ | Δ | Εικονική Ε | Προσφορά |
|---|---:|---:|---:|---:|---:|---:|
| Εργοστάσιο 1 | 50 | 60 | 40 | 0 | 0 | 150 |
| Εργοστάσιο 2 | 0 | 0 | 30 | 102 | 38 | 170 |
| Ζήτηση | 50 | 60 | 70 | 102 | 38 | 320 |

Το συνολικό κόστος της αρχικής λύσης είναι:

```text
C = 50·14 + 60·20 + 40·14 + 30·17 + 102·16 + 38·0
  = 700 + 1.200 + 560 + 510 + 1.632 + 0
  = 4.602
```

## Έλεγχος και βελτίωση με MODI

### 1η εφαρμογή MODI

Για τις βασικές μεταβλητές της αρχικής λύσης, επιλέγουμε `u1 = 0`.

Οι δυναμικές τιμές είναι:

```text
u1 = 0
u2 = 3
vA = 14
vB = 20
vΓ = 14
vΔ = 13
vE = -3
```

Οι δείκτες βελτίωσης για τις μη βασικές μεταβλητές είναι:

| Μη βασική μεταβλητή | Δij = cij - ui - vj |
|---|---:|
| x1Δ | 5 |
| x1E | 3 |
| x2A | -2 |
| x2B | -5 |

Επειδή υπάρχουν αρνητικοί δείκτες, η λύση δεν είναι βέλτιστη. Επιλέγεται η μεταβλητή `x2B`, επειδή έχει τον πιο αρνητικό δείκτη.

Ο κλειστός βρόχος είναι:

```text
x2B (+), x2Γ (-), x1Γ (+), x1B (-)
```

Η μέγιστη δυνατή μεταφορά είναι:

```text
θ = min(30, 60) = 30
```

Η νέα λύση γίνεται:

|  | Α | Β | Γ | Δ | Εικονική Ε | Προσφορά |
|---|---:|---:|---:|---:|---:|---:|
| Εργοστάσιο 1 | 50 | 30 | 70 | 0 | 0 | 150 |
| Εργοστάσιο 2 | 0 | 30 | 0 | 102 | 38 | 170 |
| Ζήτηση | 50 | 60 | 70 | 102 | 38 | 320 |

Το νέο κόστος είναι:

```text
C = 50·14 + 30·20 + 70·14 + 30·18 + 102·16
  = 700 + 600 + 980 + 540 + 1.632
  = 4.452
```
